# NutriLens — AI Fitness & Nutrition Platform

NutriLens is a modern health-tech SaaS web application that lets users photograph their food, understand its nutritional content, track meals, and receive personalized recommendations.

## Tech Stack
- **Frontend**: Next.js 15+ (App Router), TypeScript, Tailwind CSS v4
- **State Management**: Zustand
- **Visualizations**: Recharts, Lucide Icons, Canvas/SVG Circular Progress
- **Styling**: Modern dark/light glassmorphic health-tech design system

## Project Structure
- `/web`: Next.js web client with complete UI, mock data layers, interactive calorie/macro tracking, AI scan simulation, diet plans, weekly planner, and progress dashboards.
- `/api`: Planned NestJS backend with Prisma & PostgreSQL.

## Getting Started (Web)
```bash
cd web
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
